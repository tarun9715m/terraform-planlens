planlens

Open a Terraform plan

In your Terraform directory, run terraform plan -out=tfplan, then planlens tfplan. Or drop a plan JSON file anywhere on this page. Create one with terraform show -json tfplan > plan.json.

The file is read in this browser tab and never uploaded.
