# Code of conduct

planlens follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the work. Harassment, personal attacks and discriminatory language aren't accepted in issues, pull requests or any other project space.

To report unacceptable behavior, contact the maintainer, [@tarun9715m](https://github.com/tarun9715m), through GitHub. Reports are handled privately.
